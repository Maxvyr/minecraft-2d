Minecraft 2D

Commandes
Q/A, D ou ← → : se déplacer
Espace, Z/W ou ↑ : sauter / nager
Clic gauche (maintenu) : miner
Clic droit : poser un bloc
Clic droit sur l'établi : artisanat
1-9 / molette : choisir l'objet
E : inventaire & artisanat
H : afficher / masquer l'aide

Mobile
Pad ← → ↑ : se déplacer / sauter
Miner (maintenir) / Poser
Toucher le monde pour viser
Toucher la barre rapide : choisir

Inventaire

Clique deux cases pour échanger / fusionner.
La dernière ligne = barre rapide.

Artisanat

Maj + clic : fabriquer le maximum. E / Échap : fermer.
